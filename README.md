# C-V2X 车联网资源分配算法仿真平台

用 Python 模拟 **“1 个 RSU（路侧单元/基站） + N 辆行驶车辆”** 的直路场景，实现并对比 4 种无线资源块（RB）调度算法，从 **吞吐量、公平性（Jain 指数）、平均时延** 三个维度评估，并输出对比曲线、柱状图与 GIF 动画。

> 本项目以“从 0 学习车联网仿真”为起点，代码结构清晰、注释充足，适合上手阅读与扩展。

---

## 一、系统模型

1. **场景**：一条 500 米直路，RSU 位于路中心，`N` 辆车随机分布并以随机速度行驶。
2. **信道模型**：按**路径损耗**计算每辆车到 RSU 的信道增益（距离越远信号衰减越强），再由增益求信噪比 `SNR`。
3. **速率映射**：用**香农公式**把 `SNR` 映射成每辆车在单个 RB 上的速率 `Rate = BW·log₂(1+SNR)`。
4. **资源分配**：每帧 RSU 将 `N_RB` 个资源块按所选算法分给 `N` 辆车。
5. **指标统计**：
   - **吞吐量**：所有车辆速率之和；
   - **公平性**：Jain 指数 `J = (Σr)² / (N·Σr²)`，取值 `0~1`，`1` 表示绝对公平；
   - **平均时延**：`mean(1/r)`，速率越低的车等待越久，反映“被饿死”的代价。

---

## 二、4 种调度算法

| 算法 | 直觉 | 追求目标 |
|------|------|----------|
| 轮询 Round-Robin | 不分好坏，资源块轮流分配 | 绝对公平 |
| 随机 Random | 资源块随机丢给某辆车 | 朴素对照 |
| 贪心 Greedy | 每个资源块总是给信号最好的车 | 总吞吐量最大化 |
| 比例公平 PF | 兼顾“信号好多分”与“信号差也别饿死” | 吞吐量 × 公平性的平衡 |

其中**比例公平（PF）**是 4G/5G 实际系统的经典算法：每帧按“当前速率 / 历史平均速率”的比值分配，**被选中的车其历史均值上升、下次让步**，保证慢车不被永久饿死。

---

## 三、核心仿真结论（来自本仓库实际运行）

| 算法 | 平均吞吐量 (Mbps) | Jain 公平性 | 平均时延 |
|------|-------------------|-------------|----------|
| 轮询 | ~998.9 | ~0.989 | 低 |
| 随机 | ~995.9 | ~0.789 | 中 |
| 贪心 | **~1208.3** | **~0.125** | 高（饿死慢车） |
| 比例公平 | ~1000.1 | **~0.738** | 中高 |

**关键结论**
- **贪心**求总吞吐最高（较轮询约 +21%），但公平性仅 `0.125`，接近“一人独占”，大量信号差的车被饿死、时延极高。
- **比例公平（PF）** 在几乎不损失吞吐的前提下（1000 vs 999），把公平性大幅提升到 `0.738`，是“效率 vs 公平”的最佳折中。
- 这直观体现了通信调度中的经典 **吞吐量–公平性权衡（trade-off）**：追求效率就牺牲公平，需按业务场景选择算法。

## 四、运行方法

要求：Python 3.8+，需要 `numpy` 与 `matplotlib`（GIF 另需 `pillow`）。

```bash
# 安装依赖（可选，虚拟环境用）
pip install -r requirements.txt

# ① 运行完整仿真 + 生成三条对比曲线（吞吐/公平/时延）
python -m sim.run

# ② 生成柱状图 + 调度过程 GIF 动画
python -m sim.visualize
```

> 注意：因使用包内相对导入，请**以模块方式**（`python -m sim.xxx`）运行，而不是 `python sim/xxx.py`。

输出图片保存在 `results/` 目录。

## 七、可扩展方向

- **边缘计算卸载（MEC）**：让车辆把计算任务选择“本地算”或“卸载到边缘服务器”，把无线资源分配与计算卸载联合优化，贴合车联网 + 边缘计算科研方向。
- **DQN 强化学习调度**：把资源分配建模为马尔可夫决策过程，用深度 Q-Learning 学习“何时把 RB 给哪辆车”，与传统算法对比。
- **更真实信道**：加入多普勒频移、阴影衰落、遮挡，提升仿真保真度。
